# Loom Assistant

![Logo](docs/logo.png)

This is a Minecraft mod for Fabric that helps users craft banners on a loom.

## Download

You can download the mod from any of these sites:

- [GitHub releases](https://github.com/magicus/loom-assistant/releases)
- [Modrinth versions](https://modrinth.com/mod/loom-assistant/versions)
- [CurseForge](https://www.curseforge.com/minecraft/mc-mods/loom-assistant/files)

## Installation

Install this as you would any other Fabric mod. (I recommend using [Prism
Launcher](https://prismlauncher.org/) as Minecraft launcher for modded
Minecraft.)

## Support

Do you have any problems with the mod? Please open an issue here on GitHub.
